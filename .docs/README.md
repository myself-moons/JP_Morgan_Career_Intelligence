1. JCI_Project_Overview.docx
   Explains the need, goals, current proposed plan, architecture, roadmap, risks and scope.

2. JCI_SRS.docx
   Defines the system-level requirements, scope, assumptions, constraints, data requirements,

   Defines detailed functional behaviour, workflows, business rules, validation and test scenarios.

These are draft baseline documents. Update them as implementation decisions are confirmed.
The SRS describes what the system must satisfy. The FRS describes the functions and workflows
through which the user interacts with the system. The Project Overview explains why the project
exists and how it is currently proposed to be built.
